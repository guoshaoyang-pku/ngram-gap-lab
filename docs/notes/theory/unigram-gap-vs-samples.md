# 最基础版 gap：单 context、r 个样本、gap(r) ≈ (K−1)/r（2026-08-12）

## 1. 一句话结论

把 N-Gram Gap 砍到最基础的形式——**一个 context c，一个真分布 `P(·|c)`，
r 个 iid 训练样本抽成计数表 `p̂`**——gap 与样本量的关系是两个干净的结果：

- **精确恒等式**（对任意估计 `q` 逐项成立）：
  `gap(q) = CE_val(q) − CE_train(q) = Σ_c (p̂_c − P_c) log q_c`
- **主阶定律**（解析区 `r·P_c ≫ 1`，`q = p̂` 计数表）：
  `E[gap] = (K − 1)/r + O(r⁻²)`，其中 **K = 真分布 P 的支撑大小**（非零概率的符号数），
  不是 `exp(H(P))`（两者只在均匀分布时重合）。log-log 斜率精确 = −1。
- **对称劈裂**：`E[CE_val] − H = +(K−1)/2r`，`E[CE_train] − H = −(K−1)/2r`，
  H 在相减中完全抵消，gap 只剩 `(K−1)/r`。

你的例子完全符合：B:C 真分布 = 1:1（K=2），训练集抽到 1:2 只是有限样本涨落；
gap 的期望 = `1/r`，训练侧与验证侧各承担 `±1/2r` 的估计偏置，符号相反。

## 2. 设定

```
真分布      P(y|A)          （test/val 的 ground truth，无限大）
训练样本    y₁…y_r ~ iid P   （context A 下只出现 r 次）
计数表      p̂_c = n_c / r   （训练分布，MLE；可加平滑 q_c = (n_c+α)/(r+αK)）
CE_train    = E_{y~p̂}[-log p̂(y)] = H(p̂) + KL(p̂||q)
CE_val      = E_{y~P}[-log q(y)]  = H(P) + KL(P||q)
gap         = CE_val − CE_train
```

训练分布是**经验分布** `p̂`（r 个样本的计数比例），测试分布是**真分布** `P`。
`n = (n_1,…,n_K) ~ Multinomial(r, P)`。

## 3. 推导

### 3.1 精确恒等式（任何 q）

把两个 CE 展开、用 `Σ_c q_c = 1` 和 `Σ_c p̂_c = 1` 消去交叉项：

```
CE_val − CE_train
  = [−Σ_c P_c log q_c] − [−Σ_c p̂_c log q_c]
  = Σ_c (p̂_c − P_c) log q_c          ← 逐项精确，对任意 q 成立
```

取 `q = p̂`（满批收敛的计数表），且把 `KL(P||p̂) = Σ P_c log(P_c/p̂_c)`、
`H(P) = −Σ P_c log P_c`、`H(p̂) = −Σ p̂_c log p̂_c` 代入：

```
gap = KL(P||p̂) + H(P) − H(p̂)         ← 精确（p̂ 在 supp(P) 上的项）
```

### 3.2 解析区的泰勒展开（r·P_c ≫ 1）

记 `δ_c = p̂_c − P_c`，`E[δ_c]=0`，`E[δ_c δ_d] = P_c(δ_cd − P_d)/r`。
对 `E[KL(P||p̂)]` 展开到二阶（Miller–Madow 型）：

```
E[KL(P||p̂)] ≈ ½ Σ_c E[δ_c²]/P_c = ½ Σ_c (1 − P_c)/r = (K−1)/(2r)
```

对 `E[H(p̂)]`（经典熵偏置，0·log0=0）：

```
E[H(p̂)] = H(P) − (K−1)/(2r) + O(r⁻²)
```

代入 3.1 的精确式：

```
E[gap] = E[KL(P||p̂)] + H(P) − E[H(p̂)]
       = (K−1)/(2r) + (K−1)/(2r) + O(r⁻²)
       = (K−1)/r + O(r⁻²)              ★
```

**两个 +1/2r 从不同侧来**：`KL(P||p̂)` 在 val 侧抬高（模型低估真实分布）、
`−E[H(p̂)]` 在 train 侧压低（经验分布比真分布更集中、自评更乐观），
一正一负叠加成 `1/r`，H 的常数项完全消失。

### 3.3 常数的身份：support−1，不是 exp(H)−1

- 均匀 `P_c = 1/K`：`exp(H) = K = support`，两个记法一致。
- 非均匀（如 `P=[.7,.2,.1]`，K=3）：`K−1 = 2`，`exp(H)−1 ≈ 1.23`。
  MC/精确枚举都验证 `E[gap] ≈ 2/r`（见 §4），**是 K−1**。
- 早期笔记写的 `K_eff = exp(H(P))` 只在「私有等概率符号」方案里近似成立；
  一般分布下正确常数是**支撑大小 K**（解析区里每个支撑符号都被 `r·P_c ≫ 1` 解析到）。

### 3.4 未解析区（r·P_c ≲ 1）：未见符号惩罚主导

当某些符号 `r·P_c ≲ 1`（低 r 或长尾），`p̂_c = 0` 的概率不可忽略。
此时 `KL(P||p̂)` 发散，真实 gap 由**未见符号惩罚**主导：

```
E[gap] ≈ Σ_{c: 未见} P_c · log(r/(α K)) + (解析部分)
```

- 取决于模型的平滑 α（`q = p̂` 纯 MLE 时直接 +∞；加 α 后有限但随 α 增大而减小）；
- 这是真实实验里低 r 桶曲线偏离 `(K−1)/r`、且依赖平滑的原因；
- 长尾分布下「解析支撑」`K_r = #{c : r·P_c ≳ 1}` 决定主阶常数（见 §4-F）。

## 4. 数值验证（`tasks/l1_lookup_replay/gap_vs_samples_unigram.py`，纯 numpy，确定性）

**A. 精确恒等式**：任意 q，`Σ(p̂−P)log q ≡ CE_val−CE_train`，逐项断言成立。

**B. 你的例子 K=2（B:C=1:1），精确二项和**：

| r | 4 | 8 | 16 | 32 | 64 | 128 | 256 | 512 | 1024 |
|---|---|---|---|---|---|---|---|---|---|
| E[gap] | −0.381 | 0.098 | 0.067 | 0.032 | 0.0159 | 0.0079 | 0.0039 | 0.00196 | 0.00098 |
| 1/r | 0.25 | 0.125 | 0.0625 | 0.0313 | 0.0156 | 0.0078 | 0.0039 | 0.00195 | 0.00098 |
| E[CE_tr]−H | +0.885 | +0.003 | −0.032 | −0.0159 | −0.0079 | −0.0039 | −0.0020 | −0.0010 | −0.0005 |
| E[CE_val]−H | +0.504 | +0.101 | +0.035 | +0.0164 | +0.0080 | +0.0040 | +0.0020 | +0.0010 | +0.0005 |

r≳8 后 `E[gap] → 1/r` 到 4 位小数；训练/验证围绕 H 对称 ±1/2r。
r=4 的负 gap 是未解析区的「未见符号惩罚」与熵偏置竞争的结果（见 3.4）。

**C. 均匀 K=8（解析区 r≥64）**：log-log 斜率 **−1.027**，标度 **8.43 ≈ K−1=7**。

**D. 非均匀 `P=[.7,.2,.1]`（K=3）**：

| r | 256 | 512 | 1024 | 2048 | 4096 |
|---|---|---|---|---|---|
| E[gap] | 0.00796 | 0.00399 | 0.00192 | 0.00097 | 0.00049 |
| (K−1)/r = 2/r | 0.00781 | 0.00391 | 0.00195 | 0.00098 | 0.00049 |
| (exp H−1)/r | 0.00480 | 0.00240 | 0.00120 | 0.00060 | 0.00030 |

数值锁定 **K−1**，`exp(H)−1` 直接排除。

**E. 未解析区（K=2 精确）**：r=1..4 时 gap 依赖平滑 α（α=1e-6 → −6.9；α=0.1 → −1.3），
r≳8 后与 α 无关、收敛到 1/r。

**F. 长尾 Zipf K=128**：r=256 时解析支撑 K_r=47，gap≈3.08 远超 (K−1)/r=0.50；
r≥1024 全部符号解析（K_r=128），gap→(K−1)/r，斜率 −1。

## 5. 与真实实验的关系

- **逐桶 gap = (K_r(r) − 1)/r**：每个 context 用自己的解析支撑 K_r。
  频率桶合并后仍是 1/r 主阶（每桶内 K_r 近似常数），但低 r 桶的常数被未解析
  惩罚抬高——与 `synth_A_summary.json` 低 r 桶 excess 偏大的观测一致。
- **表开 vs 表关**：表开 = 本文的计数表 `q=p̂`（1/r 定律）；表关 = backbone 无计数
  记忆，val CE 被钉在 `ln K` 量级，形状不同——正好作为对照（现有分析结论不变）。
- **H 抵消是 gap 比 val CE 更干净的原因**：单看 val CE 有 +1/2r 偏置且依赖 H，
  相减后常数项与 1/2r 抵消，只剩 1/r。

## 0. 一句话结论

用户手写笔记的问题——「无 backbone 的纯 unigram 表 + l1/l2 马尔可夫过程」——**有 gap，且可以解析算**：

| 用户问题 | 答案 |
|---|---|
| 这里是否会有 gap？ | 有两层：(i) **模型类 gap** `Δ = H(T) − h > 0`（O(1) nats，只要 l1+l2>0 就有，纯解析、无 backbone 即存在）；(ii) **采样 gap** `g∞ = Σ_v (f̂_v−T_v) log f̂_v`（O(1/N)，由有限训练序列的经验频率 f̂≠T 产生）。 |
| 能否解析算出多个 epoch 的 gap？ | 能。收敛值 `g∞` 是精确闭式；其期望 `E[g∞] ≈ τ(V−1)/N`（leading order，τ 由 AR(2) 谱闭式给出）；逐 epoch 轨迹由**精确全批 GD 流** `u_{e+1}=u_e+η(f̂−q_e)` 给出（numpy 精确模拟即可，无需 torch），收敛速率 `1−ηκ`（κ=线性化矩阵最小非零特征值）。 |
| logits 理应一样吗？ | 一样。单一表格，train/val 用**同一组 logits**；fixed replay 下收敛到 `u* = log f̂`（+常数），fresh replay 下期望收敛到 `log T`。gap 不来自「train/val logits 不同」，而来自同一组 logits 被钉在 train 边际上、val 边际是 T。 |
| 与我们研究的现象一致吗？ | 部分一致：excess 随频率单调下降、低频为正（**纯解析**，无 backbone）；fixed replay 下 gap 随 epoch 增长；replay-specific（fixed vs fresh 截然不同）。**不一致**：无 sawtooth（单链无周期边界）；Δ 是模型类不可约的（unigram 永远学不会上下文），而 transformer 的 gap 是训练动力学可学、注入可消除的。定位：**无上下文基线**，隔离边际频率成分。 |

## 1. 模型与符号

词表 `V`，unigram 基分布 `T`（均匀或 Zipf），`l3 = 1−l1−l2 > 0`。过程：

```
X_{n+1} = X_n        w.p. l1   （重复当前 token）
X_{n+1} = X_{n-1}    w.p. l2   （变成上一个 token）
X_{n+1} ~ T          w.p. l3   （按词表 T 重启）
```

模型：单个 unigram 表，logits `u∈R^V`，`q = softmax(u)`，无 backbone。
train 损失 `L_train(q) = −Σ_v f̂_v log q_v`（f̂=训练序列经验频率），val 损失 `L_val(q) = −Σ_v T_v log q_v`。
观测量 `gap(q) = L_val(q) − L_train(q)`；excess 曲线 `e(v) = val 逐 token CE − h`。

## 2. 平稳分布

**单 token 边际 = T。** 对任意 a，`P(X_{n+1}=a) = l1 P(X_n=a) + l2 P(X_{n-1}=a) + l3 T(a)`，固定点即 T。

**pair 平稳分布**（`π₂(a,b) = P(X_{n-1}=a, X_n=b)`）。pair 链 `(X_{n-1},X_n)→(X_n,X_{n+1})` 的转移核：
给定 `(a,b)`，`X_{n+1}=b` w.p. l1、`=a` w.p. l2、`~T` w.p. l3。平衡方程分两类：

- 对角 `(b,b)`：`π₂(b,b) = Σ_a π₂(a,b)[l1 + l2·1[a=b] + l3 T(b)] = (l1+l3T(b))·T(b) + l2·π₂(b,b)`，故
  `π₂(b,b) = (l1 T(b) + l3 T(b)²) / (1−l2)`。
- 非对角 `b≠c`：`π₂(b,c) = Σ_a π₂(a,b)[l2·1[a=c] + l3 T(c)] = l2·π₂(c,b) + l3 T(b)T(c)`，
  代入 `π₂(c,b) = l3T(c)T(b)/(1−l2)` 得 `π₂(b,c) = l3 T(b)T(c)/(1−l2)`。

对角总质量 `π_diag = Σ_a π₂(a,a) = (l1 + l3 S₂)/(1−l2)`，`S₂ = Σ_a T(a)²`。

数值验证（脚本 A 节）：

| (l1,l2) | dist | max|π₂ 行和 − T| | max|经验 − 闭式| | π_diag 闭式 | π_diag 经验 |
|---|---|---|---|---|---|
| (0.4,0.4) | Zipf-16 | 1.4e-17 | 2.1e-3 | 0.7129 | 0.7159 |
| (0.2,0.6) | uniform-16 | 0.0 | 1.4e-3 | 0.5312 | 0.5329 |

## 3. 熵率 h 与模型类 gap Δ = H(T) − h

**条件分布。** 给定 `(X_{n-1}=a, X_n=b)`，`X_{n+1}` 的分布为
`l1·δ_b + l2·δ_a + l3·T`。条件熵分两类：

- **对角** `a=b`：质量 `l1+l2` 落在 a 上，`l3 T(c)` 落在其余 c：
  `H_diag(a) = −(l1+l2+l3T(a))·log(l1+l2+l3T(a)) − l3·Σ_{c≠a} T(c) log(l3 T(c))`。
- **非对角** `a≠b`：质量 l1 在 b、l2 在 a、l3T(c) 在其余：
  `H_off(a,b) = −(l1+l3T(b))·log(l1+l3T(b)) − (l2+l3T(a))·log(l2+l3T(a)) − l3·Σ_{c≠a,b} T(c) log(l3 T(c))`。

**熵率**（按平稳 pair 分布 π₂ 加权）：

```
h = Σ_a π₂(a,a)·H_diag(a) + Σ_{a≠b} π₂(a,b)·H_off(a,b)
```

**关键：不能按 T×T 加权**（即假设 pair 独立）。π₂ 的对角质量 `π_diag` 远大于 T×T 的对角质量 `S₂`
（例：(0.4,0.4) Zipf-16 为 0.713 vs 0.480），而对角 pair 的条件熵更低（下一步高度可预测），
因此 T×T 加权会高估熵率：实测 `h_TxT=1.276 vs h=0.998`（(0.4,0.4)），高估 0.278 nats。

**模型类 gap。** unigram 表的 Bayes val loss 是 `H(T) = −Σ T log T`（q=T 最优，边际 T）；
过程真实条件熵是 h。只要 l1+l2>0（有记忆结构），`h < H(T)`，于是

```
Δ = H(T) − h > 0
```

这是**不可约**的模型类 gap：unigram 表没有任何 logits 能低于 H(T)，永远学不会上下文。

## 4. 逐 token excess 曲线 e(v) = −log T_v − h

收敛后 `q = T`，val 逐 token CE 为 `−log T_v`。定义逐 token excess

```
e(v) = −log T_v − h
```

性质（全部解析）：
- `Σ_v T_v e(v) = H(T) − h = Δ > 0`（T-加权平均即模型类 gap）。
- **随频率单调**：`e(v)` 是 `T_v` 的严格减函数（`de/dT_v = −1/T_v < 0`）——低频 token 的 excess 大、高频小，形状与项目「excess 随 context 频率 r 单调下降、低频为正」一致。
- **穿零条件**：`e(v) < 0 ⟺ T_v > e^{−h}`。要求词表高度集中（如 V=2, T=(0.99,0.01)）；现实 Zipf 下全部为正。

数值（脚本 F 节，Zipf-64）：

| (l1,l2) | H(T) | h | Δ | e(最高频) | e(最低频) |
|---|---|---|---|---|---|
| (0.4,0.4) | 3.3714 | 1.2681 | 2.1033 | 0.289 | 4.448 |
| (0.6,0.2) | 3.3714 | 1.2050 | 2.1663 | 0.352 | 4.511 |
| (0.2,0.6) | 3.3714 | 1.3004 | 2.0710 | 0.257 | 4.415 |
| (0.8,0.1) | 3.3714 | 0.6542 | 2.7172 | 0.903 | 5.062 |

穿零 demo：`V=2, T=(0.99,0.01), (0.4,0.4)`：`H=0.0560, h=0.0220, e=[−0.012, 4.583]`——最高频 token 的 excess 为负（可穿零），低频 token 仍大正。uniform V=8 下 `e = H(T)−h = 1.136`（全部相等，不穿零）。

## 5. 采样 gap：g∞ 与 1/N 展开

对任意模型 q：

```
gap(q) = L_val(q) − L_train(q) = Σ_v (f̂_v − T_v) log q_v
```

收敛后 `q = f̂`（unigram 表全批训练只能拟合 train 边际），得到

```
g∞ = Σ_v (f̂_v − T_v) log f̂_v
```

**1/N 展开**（δ_v = f̂_v − T_v）：

```
log f̂_v = log T_v + δ_v/T_v − δ_v²/(2T_v²) + δ_v³/(3T_v³) − …
g∞ = Σ_v δ_v log T_v + Σ_v δ_v²/T_v − Σ_v δ_v³/(2T_v²) + …
E[g∞] = Σ_v E[δ_v²]/T_v + O(1/N²)
      = Σ_v (1−T_v)·τ_v/N + O(1/N²)          （E[δ_v²]=T_v(1−T_v)τ_v/N，τ_v=积分自相关时间）
```

若 τ_v 与 v 无关（§6 将证明），则 `E[g∞] ≈ τ(V−1)/N`。

**蒙特卡洛验证**（脚本 D 节，V=16 Zipf，N=2¹⁷，S=256；`E[g-vr]` 是方差缩减估计量
`g' = g∞ − Σ_v(f̂_v−T_v)log T_v`——被减项期望精确为 0，把噪声从 O(1/√N) 压到 O(1/N)）：

| (l1,l2) | 预测 τ(V−1)/N | E[g] 原始 MC | E[g'] 方差缩减 | 残差 | 残差/se |
|---|---|---|---|---|---|
| (0.4,0.4) | 0.001335 | 0.001283 | 0.001315 | −2.1e-5 | −0.7 |
| (0.2,0.6) | 0.001373 | 0.001161 | 0.001414 | +4.1e-5 | +1.3 |
| (0.6,0.2) | 0.001202 | 0.000793 | 0.001209 | +7e-6 | +0.2 |

O(1/N²) 高阶项检查：N/2 时残差 −3.4e-5 → N 时 −2.1e-5（相对预测 0.001335 约为 1.6%），
leading order 主导。逐 token 方差 `Var(f̂_v) = T_v(1−T_v)τ/N` 的 pred/emp 比值 1.05/1.07/1.06（各 se≈0.09）✓。

## 6. τ 的 AR(2) 谱推导（含对主线程笔记的一处修正）

**指示过程是条件期望意义下的 AR(2)。** 对固定 token v，令 `Y_n = 1[X_n=v] − T_v`。由于
`E[1[X_{n+1}=v] | X_n, X_{n-1}] = l1·1[X_n=v] + l2·1[X_{n-1}=v] + l3 T_v`（逐项成立，精确），减去 T_v 得

```
E[Y_{n+1} | X_n, X_{n-1}] = l1 Y_n + l2 Y_{n-1}          （精确）
```

于是自协方差 `γ(k) = E[Y_n Y_{n+k}]` 满足 `γ(k) = l1 γ(k−1) + l2 γ(k−2)`（k≥2）。

**初值**（v 无关）：
- `γ(0) = T_v(1−T_v)`。
- `γ(1) = E[Y_nY_{n+1}] = P(X_n=v,X_{n+1}=v) − T_v² = π₂(v,v) − T_v²
  = (l1T_v + l3T_v²)/(1−l2) − T_v² = l1 T_v(1−T_v)/(1−l2)`，
  故 `r(1) = γ(1)/γ(0) = l1/(1−l2)`。

**特征根。** `r(k) = l1 r(k−1) + l2 r(k−2)` 的特征方程 `λ² = l1λ + l2`：

```
λ± = (l1 ± √(l1² + 4l2)) / 2
r(k) = A λ₊^k + B λ₋^k，    A + B = r(0) = 1，  A λ₊ + B λ₋ = r(1) = l1/(1−l2)
```

> **修正（相对主线程笔记）**：笔记写 `A_v + B_v = r_v(1)`。按非移位形式 `r(k)=Aλ₊ᵏ+Bλ₋ᵏ`
> 应为 `A_v + B_v = r_v(0) = 1`；若误用 `A+B=r(1)`，会把 (0.4,0.4) 的 τ 抬高到 13.67，
> 与笔记自己的「实测 τ≈11」不符；正确初值给出 **τ = 11.667**，与实测（截断和 11.654）一致。
> 笔记中的 `r_v(2)` 公式本身正确，且化简后与 v 无关（见下），故 `τ_v = τ` 对全部 token 相同。

**r_v(2) 的显式值与 v 无关性。** 直接计算
`P(X_n=v, X_{n+2}=v) = Σ_b π₂(v,b)·P(X_{n+2}=v|(v,b)) = π₂(v,v)(l1+l2+l3T_v) + (T_v−π₂(v,v))(l2+l3T_v)
= l1·π₂(v,v) + T_v(l2+l3T_v)`，代入 π₂(v,v) 得

```
r_v(2) = [ l1(l1+l3T_v)/(1−l2) + l2 − (l1+l2)T_v ] / (1−T_v)
       = l1·r(1) + l2 = l1²/(1−l2) + l2        （与 v 无关）
```

（第二步用 l3=1−l1−l2 化简。）因此三个 token（最高频/中频/最低频）的 r(k) 应当重合——
数值：跨 token 最大差 ≤ 0.032（(0.6,0.2)），AR(2) 谱与模拟自相关最大差 ≤ 0.017 ✓。

**积分自相关时间**（闭式）：

```
τ = 1 + 2 Σ_{k≥1} r(k) = 1 + 2 [ A λ₊/(1−λ₊) + B λ₋/(1−λ₋) ]
```

| (l1,l2) | λ₊ | λ₋ | τ_theory | τ_naive=(1+ρ)/(1−ρ) | τ_emp(截断) | 低估倍数 |
|---|---|---|---|---|---|---|
| (0.4,0.4) | 0.8633 | −0.4633 | **11.667** | 5.000 | 11.654 | 2.3× |
| (0.2,0.6) | 0.8810 | −0.6810 | **12.000** | 3.000 | 11.852 | 4.0× |
| (0.6,0.2) | 0.8385 | −0.2385 | **10.500** | 7.000 | 10.161 | 1.5× |

**naive `(1+ρ)/(1−ρ)`（ρ=l1/(1−l2)）在 l2>0 时严重低估**：它只把 l2 折算进 r(1)，
却丢掉 AR(2) 的慢根 λ₊（(0.4,0.4) 的 λ₊=0.863 接近 1，拖长记忆）。l2=0 时 λ₋=0、A=1、
`τ = (1+l1)/(1−l1)` 精确（特例还原）。

## 7. 多 epoch GD：fixed vs fresh replay

unigram 表全批 GD（cross-entropy 的 logits 梯度是 `∇_u L_train = q − f̂`）：

```
u_{e+1} = u_e + η (f̂ − q_e)
```

**fixed replay（同一序列重播）**：f̂ 固定 → `q_e → f̂`，`gap_e = Σ(f̂−T)log q_e` 上升收敛到 `g∞`。

数值（V=16 Zipf，(0.4,0.4)，N=2¹⁶，S=128 条序列平均，η=0.5，800 epochs）：
- `E[gap_0]=+0.0001 → E[gap_last]=0.00297 = E[g∞]`（均值轨迹 0 个非增步，**期望意义下单调**）。
- 修正表述：**单条轨迹**并非严格单调——128 条中有 84 条出现过下降（最大单步下降 1.5e-3，
  与初始噪声同尺度）；「gap 随 epoch 增长」是**期望/系统性的**，单样本含 O(1/√N) 抖动。
- 收敛速率可解析：线性化 `u_{e+1}−u* = (I−ηD)(u_e−u*)`，`D = diag(f̂) − f̂f̂ᵀ`，
  最慢模 `κ = min{nonzero eig(D)}`，`g∞−gap_e` 按 `(1−ηκ)^e` 衰减。
  实测 ratio 0.99173 vs 理论 `1−ηκ = 0.99203`（κ=0.0159）✓。

**fresh replay（每 epoch 新采样）**：每个 epoch 的 `f̂_e` 独立于当前 q_e，故

```
E[gap_e] = Σ_v E[f̂_e,v − T_v] · E[log q_e,v] = 0        （每个 epoch 精确成立）
```

gap 不随 epoch 累积，只保留本 epoch 采样噪声。数值：最后 200 epoch 均值 −0.00045 ± 0.026（≈0）✓。
对照：fixed 的 gap 涨到 `E[g∞]≈τ(V−1)/N`，fresh 停在 0——**replay-specific**。

|---|---|---|
| excess（val CE − H）随 context 频率 r 单调下降、低频为正 | ✅ **纯解析复现** | `e(v)=−log T_v−h`，`de/dT_v<0`；Zipf-64 (0.4,0.4) 从最高频 0.289 单调升到最低频 4.448（全为正）。项目 A control 实测从 r=8192 的 +1.43 升到 r≤128 的 +8.15（`fig_synth_excess_vs_freq.svg`）——形状一致，尺度不同（toy 的 e(v) 映射到 token 频率分箱；项目是 context 频率分箱且含可学习动力学成分）。 |
| fixed replay 下 gap 随 epoch 增长 | ✅ | `E[gap_e]` 单调上升收敛到 `E[g∞]=τ(V−1)/N`（0 → 0.00297，V=16）；单样本有 O(1/√N) 抖动。 |
| replay-specific（fixed vs fresh 截然不同） | ✅ | fresh 每 epoch `E[gap_e]=0` 精确成立（独立性），不累积。 |
| sawtooth（loss 周期锯齿） | ❌ 不覆盖 | 单链无周期边界、无 block 结构；toy 的 loss 轨迹是平滑单调收敛的。 |
| gap 可由注入 n-gram 表消除 / 是训练动力学可学的 | ❌ 不一致 | toy 的 `Δ=H(T)−h` 是**模型类不可约**的：unigram 表无任何参数能达到 h（h < H(T) 恒成立），注入也没用；而项目 transformer 的 excess 在注入精确 context 计数表后降到 ≈0（A +0.071 nats）。 |
| gap 是「记忆特定」的（低频上下文靠记忆、高频靠平均） | ⚠️ 部分 | toy 没有上下文记忆，但复制了**频率轴的形状**（低频大、高频小）；这正是「无上下文基线」应隔离的边际频率成分。 |

**定位结论**：该 toy 是项目的**无上下文基线**——它证明「excess 随频率单调下降、低频为正」这个形状
甚至不需要任何上下文记忆/backbone，纯 unigram 表 + 带结构的马尔可夫源即可解析出现；
而项目的 transformer gap 中的**可学习/可注入部分**（n-gram 记忆）在该 toy 中不存在。
因此该 toy 的用途是：(i) 校准「频率形状」的基线期望；(ii) 演示 replay-specific 的 epoch 动力学
（fixed 累积、fresh 归零）在最小模型上就是解析的。

## 9. 对主线程笔记的修正清单

1. **τ 的 AR(2) 初值索引**：`A_v+B_v=r_v(1)` 应为 `A_v+B_v=r_v(0)=1`、`A_vλ₊+B_vλ₋=r_v(1)`。
   错误初值把 (0.4,0.4) 的 τ 从 11.667 抬到 13.667；笔记「实测 τ≈11」与正确值 11.667 一致。
2. **r_v(2) 与 τ_v 的 v 无关性**：笔记的 `r_v(2)` 显式公式正确，但化简后 `= l1²/(1−l2)+l2`
   与 v 无关，故 `τ_v = τ` 对所有 token 相同（数值验证：跨 token 自相关最大差 ≤0.032）。
3. **「gap_e 单调上升」的精确化**：在期望意义下单调（均值轨迹 0 个非增步）；单条固定-replay
   轨迹有 O(1/√N) 量级的非单调抖动（128 条中 84 条出现，最大 1.5e-3）。

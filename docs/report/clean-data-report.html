5. 口径说明与已知限制

  • gap 定义：val_loss − train_loss，同一 step、同一 batch 口径；novel context（train hit=0）无 train token loss，不进 gap。
  • val：fixed validation batches（固定一组 batch），非移动窗口。
  • compute dtype：旧 _fixed run 为 fp32；v2 新标准为 bf16 + torch.compile（已验证逐点复现，gap 差 <0.1）。
  • 表优化器：所有 run 显式 --table_betas 0.0,0.999（旧）或 0.0,0.99（v2 新标准），无动量。
  • 数值回填：experiment-log.md 全文数值仍在 pre-fix 状态（§1 注），v2 完成后统一回填。

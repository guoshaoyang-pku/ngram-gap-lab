ngram-gap-lab 实验报告

日期：2026-08-14 ｜ 研究问题：n-gram value table 引发的 train/val gap 与 epoch 边界跳变现象

〇、实验基础设施（所有组共用）

模型

vanilla nanoGPT：8 层 Transformer，6 头注意力，d_model=768，序列长度 2048，词嵌入与 lm_head 权重共享。vocab_size 随数据集变化（8192 或 256）。

Bigram value table（可选开关）：哈希压缩的 bigram 嵌入表。

  • 查表键：(prev_token, cur_token) 经两个哈希函数，K=2，各产生 d_model/2 维向量后拼接
  • 表大小：vocab × 64 行（vocab 8192 时 52.4 万行；vocab 256 时 1.6 万行）
  • 放置位置：交替的 4 个 VE 层（layer 1/3/5/7）
  • 注入方式：input 注入，把各层 bigram 向量求和后直接加到 token 嵌入上，再进入 Transformer

优化器（双组混合）

参数组优化器超参数
Backbone（注意力、MLP、嵌入）AdamWlr=0.004, β=(0.8, 0.95), weight_decay=0.1（仅 2D 矩阵）
Bigram tableRMSPropβ=(0.0, 0.999)，无动量，无 weight decay

训练流程（所有组一致）

  • 3000 步，batch 72 条序列，梯度累积 =1
  • 固定顺序回放：每个 epoch 按相同顺序重读全部训练序列，无打乱
  • 验证：每 5 步测一次，每次 4 个 batch
  • 学习率：前 35% 步数线性预热到 1.0，之后线性衰减到 0.05
  • 数据规格：每个 shard 22000 条序列，每条 2049 个 token（1 train shard + 10 val shards）

一、数据实验组（Transformer + bigram）

本组固定模型不变，只改变数据生成方式，观察 gap 和 epoch 边界行为。

实验 A1：原版 Markov 数据（vocab=8192，全局 λ=0.8）

数据生成：

P(xj+1 | xj) = 0.8 · I[xj+1 = xj] + 0.2 · π(xj+1)

π 的构成为：token 0 占 30% 质量，其余 8191 个 token 均分剩余 70%（每个约 0.0085%，带 ±δ 微扰）。所有序列共享同一个 λ 和 π，序列之间统计同分布。

模型设置：vocab=8192，bigram 表 52.4 万行。总参数 1675M（backbone 约 65M + bigram 表约 1600M）。

结果：baseline（关 bigram）gap +0.13；开 bigram 后 gap +0.73。gap 在 epoch 内平滑爬坡，epoch 边界处没有跳变（边界跳变幅度仅 ±0.03）。

机制分析：训练集只覆盖 67M 个可能词对中的 6.4%。哈希碰撞 8:1。分桶分析显示 gap 的 58% 来自 novel 桶（训练中从未出现的词对），table 对这些词对输出随机初始向量，纯有害。

实验 A2：perseq 数据（每序列专属 λk ~ U(0.4, 0.95)）

数据生成：在原版基础上，每条序列 k 拥有自己的黏着率 λ_k，从均匀分布 U(0.4, 0.95) 独立采样：

Pk(xj+1 | xj) = λk · I[xj+1 = xj] + (1−λk) · π(xj+1)

λ_k 即序列身份。设计意图：table 可以背住每条训练序列的黏着度（重读时 recall），backbone 需要同时学 22000 个不同的 λ 值。

模型设置：与 A1 完全相同（vocab=8192，bigram 开）。

结果（跑至 4-5 epoch 后提前停止）：前 4 epoch 平均 gap +0.79，同期原版只有 +0.28，放大近 3 倍。epoch 边界动态明显活跃：1→2 边界跳 −0.49（反向），2→3 跳 +0.21，3→4 跳 +0.35；原版数据的边界始终只有 ±0.03。

机制分析：1→2 边界是负跳，原因是 epoch 1 末尾 table 刚背完尾部序列，epoch 2 重读头部序列时，table 对头部词对的记忆已被 epoch 1 全程的训练覆盖（哈希碰撞干扰），recall 失败，train loss 反而回升。2→3、3→4 的正跳说明 table 记忆稳定后重读红利开始显现。

实验 A3：doc 共享字典数据（vocab=256，10% 确定性共享 pair 映射）

数据生成：vocab 缩小到 256 个共享词。每步生成：

xj+1 = g(xj-1, xj)（概率 0.1）；否则走原版 Markov 步（λ=0.8, π₁=0.3）

g 是一本全局固定的随机字典（256×256=65K 个词对，输出均匀分布在 256 词上），train 和 val 用同一本字典。设计意图：共享词对每 epoch 曝光约 690 次，table 有足够的记忆质量；同时保持 90% 的原版 Markov 背景作为主数据。

模型设置：vocab=256，bigram 表 1.6 万行。总参数 108.8M。其余与 A1 相同。

结果（跑至 5 epoch 提前停止）：gap +0.02，完全消失。无边界跳变，loss 平滑缓降（table 在稳定地记忆共享字典）。

机制分析：train 和 val 的生成规律完全相同，词对覆盖率接近 100%。table 记忆的字典内容对 val 完全有效。数据中不存在只对 train 有效、对 val 无效的信息，gap 失去了来源。这一组验证了共享高频词的正面效果（table 能快速记忆），同时暴露了缺失的要素：train/val 的转移律需要不对称。

数据组总结：gap 的产生需要两个条件同时满足。条件一，table 能快速记忆：共享高频词、低哈希碰撞（A3 满足；早期私有词设计因每词对每 epoch 仅曝光约 4 次而失败）。条件二，被记忆的信息 train 专属：转移律在 train/val 间不对称，或覆盖率低到经验估计偏离真值（A1 靠 6.4% 覆盖率的噪声，A2 靠序列级 λ 的经验统计）。下一步计划：在 A3 基础上加 map_shift 参数，train 用 g_train、val 用 g_val，置换部分词对。

二、MLP 实验组（原版数据 vocab=8192）

本组固定数据为原版 Markov（λ=0.8），研究 backbone 架构、dropout、bigram table 的相互作用。

MLP backbone 结构

大版本（h4096d4）：单块，无注意力，无残差连接：

LN(768) → Linear(768→4096)+GELU → Linear(4096→4096)+GELU ×2 → Linear(4096→768) → Dropout

小版本（h1024d2）：768→1024→768 两层。dropout 加在 MLP 输出后和 token 嵌入后两处。bigram 表设置与 Transformer 组相同（input 注入）。

主要发现

  • 纯 MLP 自身过拟合严重：MLP baseline gap +0.497，Transformer baseline 只有 +0.131。注意力结构带有泛化归纳偏置，纯 MLP 逐位置独立处理，缺乏该偏置，在固定回放下会直接记忆数据。
  • bigram table 显著放大 gap：MLP 从 +0.497 升到 +0.935；Transformer 从 +0.131 升到 +0.727。table 是显式记忆通道，学习速度超过 backbone，垄断训练信号。
  • dropout 对两类 gap 效力不同：对 backbone 过拟合，dropout=0.2 削减 58%（+0.497→+0.208）；对 bigram gap，只削减 38%（+0.935→+0.582）。dropout 作用于 backbone 前向传播，table 里的精确 key-value 记忆不受其影响。
  • backbone 尺寸对 gap 无影响：bigram 开启时，h1024d2（10M 参数）与 h4096d4（48M 参数）的 gap 几乎相同（+0.610 vs +0.582）。gap 由 table 主导。
  • dropout 的时间效应：epoch 1-6 阶段 dropout=0.2 的 gap 略高于 dropout=0（dropout 拖慢学习），两条曲线在 epoch 7 交叉，之后无 dropout 版进入记忆爆发（epoch 10 达 +0.935），dropout 版被压住（+0.582）。

三、总体结论

  1. gap 的两个必要条件：table 能快速记忆（共享高频词、低碰撞）；被记忆的信息 train 专属（转移律不对称或有限样本噪声）。缺一即无 gap。
  2. epoch 边界跳变要求重读时 table 瞬间 recall train 专属记忆。共享平稳数据中该记忆不存在；纯私有罕见词因曝光不足记不住。两者需要结合。
  3. backbone 处于配角地位：Transformer 的注意力归纳偏置使 baseline 过拟合远低于 MLP；bigram 开启后 gap 由 table 主导，backbone 尺寸和 dropout 只能影响小部分。
  4. 下一步：在共享字典数据上加 train/val 字典置换（map_shift 参数），同时获得快速记忆与不可迁移性。
